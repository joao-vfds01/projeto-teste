## Projeto Busca CEP

Projeto Java que consome a API ViaCEP para buscar informações de endereço a partir de um CEP.

Tecnologias
- Java
- Gson
- HttpClient
- API ViaCEP

Funcionalidades
- Busca de CEP
- Conversão JSON
- Geração de arquivo JSON
- Tratamento de exceções

Como executar
1. Clone o projeto
2. Execute a classe Principal
